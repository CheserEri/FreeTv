# YTV 系统架构与服务契约 v0.1

## 1. 架构决策

P0 不建设远程后端。应用采用“本地应用服务 + 官方 WebView 适配器”结构，避免凭空假设或调用非公开官方接口。

```text
Flutter Presentation
      │
Application Services ── ChannelRepository / HistoryRepository
      │                              │
Domain Models                    SQLite (YTV 本机)
      │
PlaybackGateway ── OfficialWebPlaybackGateway ── 官方 WebView
```

未来若取得官方书面允许的接入方式，可新增 `OfficialApiAdapter`；不得替换为抓取网页、重放请求或解析播放流的实现。

## 2. 领域模型

```ts
type Channel = {
  id: string;             // YTV 稳定 ID，例如 cctv-1
  name: string;
  category: 'cctv' | 'satellite' | 'other';
  logoAsset?: string;
  officialPageUrl: string; // 官方公开页面地址，不是媒体地址
  availability: 'unknown' | 'available' | 'restricted';
};

type WatchHistory = {
  channelId: string;
  openedAt: string;       // ISO-8601
  lastProgramTitle?: string;
};

type PlaybackState =
  | { kind: 'idle' }
  | { kind: 'loading'; channelId: string }
  | { kind: 'playing'; channelId: string }
  | { kind: 'needsOfficialLogin'; channelId: string }
  | { kind: 'restricted'; channelId: string; message: string }
  | { kind: 'failed'; channelId: string; retryable: boolean; message: string };
```

## 3. 前端服务接口

```ts
interface ChannelRepository {
  list(category?: Channel['category']): Promise<Channel[]>;
  search(query: string): Promise<Channel[]>;
  getById(id: string): Promise<Channel | null>;
}

interface FavoriteRepository {
  list(): Promise<string[]>;
  set(channelId: string, favorite: boolean): Promise<void>;
}

interface HistoryRepository {
  list(limit: number): Promise<WatchHistory[]>;
  recordOpened(channelId: string, programTitle?: string): Promise<void>;
  clear(): Promise<void>;
}

interface PlaybackGateway {
  open(channel: Channel): Promise<void>;
  setFullscreen(enabled: boolean): Promise<void>;
  observeState(): AsyncIterable<PlaybackState>;
  close(): Promise<void>;
}
```

`OfficialWebPlaybackGateway.open` 只允许导航至 `Channel.officialPageUrl` 的受信任官方域名。它不暴露 Cookie、Token、DOM 内容、媒体 URL 或网络请求给应用其他层。

## 4. 未来 BFF HTTP 契约（仅在有正当数据授权时启用）

为让客户端可以先行开发，预留下列**自有服务**契约；它们不是央视频接口，也不应被用来代理、缓存或转发受保护媒体。

| 方法 | 路径 | 用途 |
|---|---|---|
| `GET` | `/v1/catalog/channels?category=cctv` | 已获授权的频道目录 |
| `GET` | `/v1/catalog/channels/{id}` | 单频道展示信息 |
| `GET` | `/v1/catalog/channels/{id}/schedule?date=YYYY-MM-DD` | 已获授权的节目单 |
| `GET` | `/v1/config/client` | 功能开关与最低版本 |

统一响应：

```json
{
  "data": {},
  "meta": { "requestId": "uuid", "generatedAt": "2026-09-18T00:00:00Z" }
}
```

统一错误：

```json
{
  "error": { "code": "CATALOG_UNAVAILABLE", "message": "频道目录暂不可用", "retryable": true },
  "meta": { "requestId": "uuid" }
}
```

禁止的端点：播放 URL 获取、Token/Cookie 交换、账号代理、DRM 许可证代理、任何媒体转发接口。

## 5. 安全与隐私

- 白名单仅允许 `yangshipin.cn` 及其页面运行所需的官方 HTTPS 子域；具体清单应在 POC 观察后审核，不以通配符放宽；
- 禁止 WebView 的任意 JS bridge；如确有需要，只允许无敏感参数的单向状态通知，并逐项评审；
- 本地数据库仅保存应用偏好、频道 ID 和观看时间；提供“清除历史”入口；
- 日志不得记录地址参数、认证头、Cookie、网页正文或媒体链路。
