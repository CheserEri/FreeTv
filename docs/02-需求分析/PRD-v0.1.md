# YTV 产品需求文档（PRD）v0.1

**状态：** 可开发基线  
**范围：** Windows MVP，后续适配 Android 与 Android TV  
**原则：** 官方内容、官方认证、最小权限、可替换播放适配层。

## 1. 产品目标

让用户在 Windows 上用简洁的电视式界面发现频道、快速进入官方直播页、全屏观看，并保存仅属于本机的收藏和观看历史。

### 1.1 成功标准

1. 启动后 2 秒内显示本地首页骨架与缓存频道；
2. 用户可在 3 次以内操作进入 CCTV-1；
3. 官方页面在 WebView 内可打开并播放其允许播放的内容；
4. 退出后收藏、历史和偏好可恢复；
5. 在网络、登录过期或页面加载失败时给出可理解且可恢复的提示。

### 1.2 非目标

- 不采集或代管官方账号、Cookie、Token；
- 不请求、缓存或分享播放地址；
- 不尝试将网页媒体流转交给第三方播放器；
- 不承诺所有频道、会员内容或地区限制内容可播放。

## 2. MVP 用户流程

```text
启动
  └─ 首页（继续观看 / CCTV / 收藏）
       └─ 选择频道
            └─ 播放页
                 ├─ 官方电视页面载入与播放
                 ├─ 全屏 / 返回频道列表
                 └─ 需要登录时进入官方登录页面
```

## 3. 页面与功能

| 页面 | P0 功能 | 验收条件 |
|---|---|---|
| 启动页 | 初始化本地存储、读取缓存 | 无网时仍可进入首页 |
| 首页 | 焦点频道、继续观看、CCTV 横向列表 | 可选择卡片进入播放 |
| 频道页 | CCTV 分类、搜索、收藏切换 | 键盘上下左右和 Enter 可操作 |
| 播放页 | 官方 WebView、加载/错误态、全屏、返回 | 公开可播内容能在 WebView 中播放 |
| 收藏页 | 本机收藏频道 | 添加/删除实时反映 |
| 设置页 | 自动播放、主题、清除本地历史 | 不含官方账号凭据管理 |

## 4. 数据边界

| 数据 | 归属 | 存储策略 |
|---|---|---|
| 频道目录、节目单 | 官方页面或未来经许可的数据源 | P0 仅内置少量展示元数据与本地缓存 |
| 官方登录状态 | 官方站点 WebView | 由 WebView 受控；YTV 不导出 |
| 收藏、历史、设置 | YTV 本机 | SQLite/安全本地存储 |
| 播放会话 | 官方页面 | 仅记录频道 ID 与打开时间，不记录流地址 |

## 5. 需求优先级

**P0：** Windows、CCTV-1 入口、官方播放页、全屏、收藏、历史、错误提示、键盘操作。  
**P1：** CCTV 可用频道、卫视目录、节目单展示、Android。  
**P2：** Android TV 焦点体系、遥控器优化、画中画、多窗口。
