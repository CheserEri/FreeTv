# YTV 前端设计规范 v0.1

## 1. 设计方向

**“安静的客厅界面”**：深色、沉浸、内容优先。参考电视操作的清晰层级，而非把网页播放器原样搬入应用。

- 情绪：克制、可信、舒适；
- 结构：大卡片、明确焦点、少量浮层；
- 适配：Windows 键盘/鼠标优先，Android TV 以十英尺距离可读为约束；
- 无障碍：不只依赖颜色，所有焦点和状态均有文字或图标说明。

## 2. 视觉令牌

| 名称 | 值 | 用途 |
|---|---|---|
| `bg.canvas` | `#0B0D12` | 页面底色 |
| `bg.surface` | `#151922` | 导航、卡片基底 |
| `bg.elevated` | `#202633` | 悬浮层、选中背景 |
| `text.primary` | `#F5F7FA` | 标题与主内容 |
| `text.secondary` | `#AAB3C2` | 元信息 |
| `brand.primary` | `#E63B3F` | 主操作、直播状态 |
| `focus.ring` | `#74B9FF` | 键盘/遥控器焦点 |
| `state.warning` | `#F3B949` | 受限或待操作状态 |

字体使用系统无衬线：Windows 为 Segoe UI / Microsoft YaHei；Android 为 Roboto / Noto Sans SC。正文最小 14sp，TV 最小 20sp；时间与节目元信息使用等宽数字特性。

## 3. 布局与组件

桌面内容最大宽度 1440px、左右边距 40px；TV 横向安全边距 72dp。采用 8pt 间距体系：8、12、16、24、32、48。

| 组件 | 规格 | 交互状态 |
|---|---|---|
| ChannelCard | 16:9，圆角 12，频道名/当前节目 | 默认、悬停、焦点、收藏、不可用 |
| Rail | 横向可滚动频道行 | 焦点进入时自动保证卡片可见 |
| PlayerShell | 16:9 黑色视频区 | 加载、播放、受限、网络失败 |
| SideNav | 图标 + 文字，固定左侧 | 当前项使用品牌色指示条 |
| Toast | 右下非阻塞提示 | 成功 3 秒；错误保留至关闭 |

焦点态必须有 `2px #74B9FF` 外环与轻微放大（`1.03`），且不依赖 hover。遥控器/键盘映射：方向键移动焦点；Enter 确认；Esc 返回；Space 仅在官方页获得焦点时交由官方页面处理。

## 4. 页面线框

```text
┌──────┬──────────────────────────────────────────────────┐
│ YTV  │  晚上好                         搜索 / 设置      │
│ 首页 │  继续观看                                         │
│ 频道 │  [ CCTV-1 当前节目                         ]      │
│ 收藏 │                                                    │
│ 设置 │  CCTV                                             │
│      │  [CCTV-1] [CCTV-2] [CCTV-3] [CCTV-5] ...          │
└──────┴──────────────────────────────────────────────────┘
```

播放页将官方网页放置于 `PlayerShell` 内。YTV 只提供壳层的返回、全屏、加载与网络提示；不叠加可能遮挡官方登录、授权或版权提示的控件。

## 5. Flutter 实现约束

- 使用 Material 3 的主题令牌和自建组件，不直接在页面中散落色值；
- 页面状态使用 `loading / data / empty / error` 四态；
- 首次版本只做深色主题；浅色主题留作令牌扩展，不做半成品入口；
- WebView 与 UI 通过 `PlaybackGateway` 隔离，页面组件不持有 WebView 控制器。
